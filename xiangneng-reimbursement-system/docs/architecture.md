# 祥能报销系统 V0.2 架构

## 模块

- `src/domain/reimbursement.js`
  - 金额计算；
  - 三张汇总表；
  - 打印包排序；
  - 发票类型与金额本地模拟识别；
  - 自动校验。
- `src/domain/workflow.js`
  - 七个主状态；
  - 合法状态流转；
  - 问题标记与解决；
  - 整批审核约束。
- `src/data/demo-data.js`
  - 合成演示人员、项目、批次和附件。
- `src/ui/templates.js`
  - 报销人、部门制单、负责人、财务、付款五类角色视图。
- `src/app.js`
  - 浏览器状态；
  - 表单、筛选、下钻、导出、打印和状态操作；
  - localStorage 演示持久化。

## 单一数据源

所有端口都读取和修改同一个 `batch`：

- 明细是唯一业务数据；
- 表1、表2、表3由明细计算；
- 打印包由明细附件计算；
- 付款清单由表2同一聚合函数生成；
- 问题标记独立于批次主状态。

## 正式版迁移建议

1. 将 Domain 层迁移到 TypeScript 并保持函数接口；
2. 将 `localStorage` 替换为数据库与 API；
3. 将附件 Data URL 替换为对象存储；
4. 将文件名识别替换为 OCR Provider；
5. 加入正式身份认证、部门权限和操作审计；
6. 保留三张表和打印包由明细自动生成的原则。
